ABOUT THE RADAR

Finding open-source AI agents worth building with

AI Agent Radar is an independent research layer for agent frameworks, MCP tools, copilots and autonomous workflows. The feed refreshes every six hours so builders can find credible projects without manually sorting through GitHub noise.

How listings are selected

We monitor public GitHub repositories connected to agents, autonomous workflows, MCP, copilots and automation. Projects are filtered using adoption, maintenance, relevance and momentum signals, then organized into practical categories.

How Radar Score works

Radar Score combines six public signals: adoption, maintenance activity, repository quality, relevance, open-Issue demand evidence and observed star momentum. It is a discovery aid—not a security audit, paid placement or guarantee of quality.

Our principles

  • Every listing and discovery feature is free.
  • Paid placements do not influence Radar Score.
  • We do not sell user data.
  • External product information may change, so visitors should verify important details with the provider.

AI Agent Radar is an independent research project and is not affiliated with GitHub or the listed projects. Repository names and metadata remain the property of their respective owners.
